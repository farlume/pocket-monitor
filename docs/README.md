# Documentation / 文档导航

Pocket Monitor turns an Android phone into an HDMI video monitor through a UVC capture card. Start with the product guide; no computer-side sender app is needed.

随身屏通过 UVC 采集卡在 Android 手机上查看 HDMI 视频。先阅读产品指南，电脑无需安装发送端程序。
