## English

Development preview for Android 8.0+, versionCode 3.

This release is built and published automatically from the `v0.1.2` tag using the dedicated Release signing key. Main-branch pushes run CI only; version tags run tests, Release lint, signed builds and asset publishing.

- Install `pocket-monitor-0.1.2-release.apk` on your phone.
- The AAB is for future store distribution and cannot be installed directly.
- This can update a 0.1.1 Release build signed with the same key. Uninstall an older Debug build first; uninstalling clears saved capture formats.
- `SHA256SUMS` covers the accompanying assets. `BUILD_INFO.json` records the source commit and signing certificate fingerprint.
- Assets include the matching project source, pinned UVCAndroid AAR and source archive, and third-party licenses.

Features include UVC video preview, rotation, zoom, fullscreen, saved formats and bounded startup recovery. Real HDMI capture on a phone has not yet been validated. Audio, recording, keyboard/mouse forwarding and iPhone support are not included.
