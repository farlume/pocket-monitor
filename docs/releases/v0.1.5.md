## 简体中文

- 新增蓝牙键盘与触控板，明确选择已配对电脑；支持 ASCII 文本、鼠标移动、点击和滚轮。
- 104 键 ANSI 布局包含完整标点、F1–F12、导航键、数字键盘和独立的左右 Shift / Ctrl / Option / Command。支持单次组合键及多指按住，最多六个普通键和八个修饰键同时按下。
- 提供 Mac 键盘识别辅助：左 Shift 右边为 Z，右 Shift 左边为 /，按助理提示选择 ANSI。尚未验证真实 Mac 收键和识别流程，不模拟 Apple 专有 Fn/地球键或 Touch ID。
- 新增键鼠页面和预览快捷面板，切页保留视频组件；后台、停止和异常时清空队列、尝试释放按键并注销，返回后需手动启用连接。
- 调整 UVC 格式切换、重复连接与 USB 授权时序，增加视频 Bulk IN 端点清理。设备页可复制连接诊断，包含连接阶段、USB 速率/端点及受限的本进程 UVC 日志，不包含视频或键盘输入，也不会自动上传。

**已知未解决：** 用户反馈 OPPO PLG110 / Android 16 搭配 UGREEN 95348（USB `2b89:5348`）从可用的 720p 格式切换后无帧，自动降级与手动切回仍可能失败，需拔插恢复。本版不宣称修复完成，也不能据此认定设备仅支持 720p。蓝牙与 HDMI 同时使用尚待真机验证。

## English

- Adds Bluetooth keyboard and touchpad with explicit paired-host selection, US-layout ASCII text, pointer movement, clicks and scrolling.
- A 104-key ANSI layout includes punctuation, F1–F12, navigation, a number pad and independent left/right Shift, Ctrl, Option and Command. Supports one-shot shortcuts and multi-touch holds with up to six ordinary keys and eight modifiers.
- Mac setup helpers send Z beside left Shift and / beside right Shift, with an ANSI selection hint. Real Mac input and setup have not been validated. Apple-specific Fn/Globe and Touch ID are not emulated.
- A Keyboard tab and preview panel keep the video view mounted. Backgrounding, stopping or errors clear queued input, attempt to release keys and unregister; returning requires manual activation and connection.
- Revises UVC format switching, duplicate connection requests and USB permission timing; adds video Bulk IN endpoint cleanup. Copyable diagnostics include connection stages, USB speed/endpoints and a bounded excerpt of this process's native UVC logs, without video, keyboard input or automatic uploads.

**Known unresolved issue:** the reported OPPO PLG110 / Android 16 with UGREEN 95348 (USB `2b89:5348`) can stop delivering frames after switching from a working 720p mode. Fallback and switching back may fail until the cable is reconnected. This release does not claim to fix it or establish that only 720p is supported. Simultaneous Bluetooth input and HDMI capture still need hardware testing.

VersionCode 6, signed with the existing Release key, supports updating same-key v0.1.4 installations. Local `-uvc-*` and `-keyboard-ansi` Debug builds use a different key and must be uninstalled first, clearing local settings. Install the APK; AAB and source ZIP files are not directly installable. Matching source, offline documentation, third-party material, build information and SHA-256 checksums accompany this release.

This remains a development build. Automated tests and UI screenshots do not replace hardware validation. Audio, recording, screenshots, concurrent capture, BIOS/pre-boot input and iPhone are not supported. Project licensing awaits the owner's choice; third-party licenses are included separately.
