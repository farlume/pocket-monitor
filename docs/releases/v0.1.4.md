## English

- Rounded launcher icon background.
- Clearer bilingual product introduction, quick start, screenshots and download links. Expanded contribution and security-reporting guides.
- New offline documentation ZIP includes both READMEs, screenshots, guides and third-party license texts. Extract the full archive to preserve image and document links.
- Standalone README attachments use online image and document links pinned to the release commit.
- Ten packaging tests check documentation completeness, release metadata and checksums. Version tags now automatically publish a regular GitHub Release marked Latest; main only runs CI.

Android 8.0+, versionCode 5, signed with the existing Release key. Install `pocket-monitor-0.1.4-release.apk` to update the same-key v0.1.3 Release installation. Debug installations use a different key; uninstalling them clears local settings. The AAB is for store distribution. Source, offline documentation, third-party material, `BUILD_INFO.json` and `SHA256SUMS` accompany the package.

This remains a development build even though GitHub lists it as a regular Release. Automated tests do not validate USB video transfer; no phone/card combination has completed real HDMI validation. Audio, recording, screenshots, concurrent capture and iPhone are not supported. Project licensing is still awaiting the owner's choice; third-party license texts are included separately.
