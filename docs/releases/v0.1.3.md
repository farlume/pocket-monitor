## English

- New **Preview, Devices and Settings** tabs. Switching tabs keeps the preview view mounted; capture still uses one card at a time.
- Choose system/light/dark appearance and Mint/Ocean/Amber colors.
- Switch between English, 简体中文 and system language immediately, without resetting the preview view.
- Save appearance, language, keep-awake and frame-stat preferences locally.
- Read bundled third-party licenses offline from Settings. Updated bilingual usage guides include screenshots of all three tabs.
- Multiple attached cards now require an explicit selection; an unplugged selection never falls back to another card automatically.

Android 8.0+, versionCode 4, signed with the existing Release key. Install the `pocket-monitor-0.1.3-release.apk` asset; it can update v0.1.2 with the same signing key. The AAB is for store distribution. Source, third-party material, `BUILD_INFO.json` and `SHA256SUMS` accompany the package.

This remains a development release. UI/model/persistence tests do not validate USB video transfer. No phone/card combination has completed real HDMI validation. Audio, recording, screenshots, concurrent capture and iPhone are not supported.
