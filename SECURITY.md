# Security reports

**English** · [简体中文](SECURITY.zh-CN.md)

## Maintenance scope

This project is in early development. Security fixes target `main` and subsequent current releases; there is no long-term maintenance commitment for older versions. See [README](README.md) and the [validation record (中文)](docs/VALIDATION.md) for current status and hardware limitations.

## Report privately

Private vulnerability reporting is enabled. For potential unauthorized USB access, sensitive-data exposure, dependency vulnerabilities or crashes caused by malicious video input, use [Report a vulnerability](https://github.com/farlume/pocket-monitor/security/advisories/new) on the repository’s Security page.

If no private reporting option is available, open an issue that only asks for a private contact channel. Do not include vulnerability details, exploit code, private logs or affected users’ data. Wait for a maintainer to provide a private channel before sending those details.

Include the affected version or commit, Android and capture-card environment, impact, minimal reproduction steps and known mitigations. Test only devices you own or are authorized to test. Use the regular Bug template for ordinary connection problems.

Maintainers will discuss verification, fixes and disclosure privately. There is no guaranteed response time or bug bounty.
